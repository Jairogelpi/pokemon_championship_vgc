# champions-research

Aplicar dentro de este repositorio y del alcance asignado. Las rutas siguientes son relativas a la raíz del repo; localizarla por AGENTS.md. No otorga permisos adicionales ni arranca otros agentes por sí sola.

1. Abrir fuentes reales, fijar fecha/commit/licencia de código y datos; no inferir soporte por el nombre.
2. Separar reglas por formato/temporada y compatibilidad por mecánica; registrar entradas no soportadas.
3. Verificar SP, Mega, roster y ejemplos dudosos; no copiar reglas de otra generación como fallback.
4. Entregar manifest y referencias para fixtures; comparar linaje de oráculos antes de afirmar independencia. Si falta acceso, marcar bloqueo, no inventar resultado.
